📖 Manual Operativo y Guía del Usuario

Documentación integral sobre estructuración EAV, versionado, bajas lógicas y operabilidad de la plataforma SRF.

Índice: 1. Roles 2. Dashboard 3. Diseñador 4. Modelo 5. Ficha 6. Preguntas

👤 1. Roles y Niveles de Acceso

El Sistema de Registros Flexibles (SRF) contempla una estructura jerárquica de permisos:

  • Administrador Super: Acceso total, gestión de usuarios globales y auditoría general.
  • Administrador Departamental: Diseña, modifica y suspende repositorios de su área de competencia.
  • Operador de Carga: Registra nuevos datos, consulta fichas mediante el botón Ver y aplica modificaciones con registro de versionado.

📊 2. Dashboard y Control Institucional

Muestra las tarjetas de repositorios asignados a su departamento. Cada tarjeta ofrece resúmenes de registros y una botonera inferior de control:

  • Ingresar: Abre el listado de datos del repositorio.
  • Modificar: Abre el diseñador para reorganizar campos o agregar nuevos atributos.
  • Suspender / Reactivar: Pausa temporalmente la carga de nuevos registros sin afectar las lecturas.

⚙️ 3. Guía Paso a Paso: Crear, Modificar y Suspender Repositorios

Desde la pestaña Crear Repositorio (o desde la opción Modificar en el pie de tarjeta del Dashboard o Modificar Estructura en el listado), el Administrador gestiona la estructura de datos:

  1. 1Identificación: Ingrese o actualice el Nombre del Repositorio y su descripción u objetivo institucional.
  2. 2Agregar / Reorganizar Atributos: Presione el botón + Agregar Campo para sumar atributos, o reordene los existentes usando las flechas ↑ (arriba) y ↓ (abajo).
  3. 3Configuración de Atributos:
    • Nombre del Campo: Título visible del atributo.
    • Tipo de Dato: Seleccione entre Texto Corto, Número, Fecha, Booleano (Sí/No) o Lista (Select).
    • Obligatorio: Marque la casilla si el dato es requerido para guardar.
    • 🔍 Buscable: Habilite esta casilla para incluir el campo en el Buscador Avanzado.
  4. 4Fijar Orden Único (↑ / ↓): Utilice los controles de ordenamiento. El primer campo oculta la flecha hacia arriba (`↑`) y el último oculta la flecha hacia abajo (`↓`).
  5. 5Protección de Datos Históricos (Inactivación de Atributos): Si remueve un campo mediante el botón ✕, el sistema solicitará confirmación. Si el campo posee datos registrados previamente, estos nunca se borran físicamente de la base de datos. El atributo pasa a estado inactivo para resguardar la validez y trazabilidad legal.
  6. 6Guardar Repositorio: Presione Guardar Repositorio y confirme en la ventana emergente.

🔍 4. Modelo EAV y Buscador Avanzado

Gracias al modelo Entidad-Atributo-Valor, la base de datos almacena la información de forma totalmente flexible. Los campos marcados como 🔍 Buscable generan índices y columnas virtuales que permiten realizar búsquedas complejas con operadores AND/OR sin penalizar el rendimiento.

📜 5. Acceso Único mediante 'Ver', Ficha Completa y Versionado

En las tablas de listado, cada registro muestra únicamente el botón Ver:

  • Al pulsar Ver, se abre la ficha completa en un modal que se amplía en un 50% respecto al tamaño estándar, organizando los atributos consecutivamente en 2 columnas paralelas.
  • El modal exhibe la insignia de versionado sobria (ejemplo: v2) si el dato sufrió modificaciones pasadas y despliega la trazabilidad histórica completa.
  • En el pie del modal se encuentran centralizadas las acciones de Cerrar, Bajar (inactivación) y Editar. Toda modificación requiere confirmación previa y genera una nueva versión.

❓ 6. Preguntas Frecuentes

¿Qué ocurre si suspendo un repositorio?
Los datos existentes siguen estando disponibles para lectura y consulta, pero el botón + Nuevo Registro queda inhabilitado hasta que presione Reactivar.

¿Puedo recuperar un registro dado de baja?
Sí, abriendo la ficha del registro inactivo mediante el botón Ver y presionando la opción Restaurar / Activar al pie del modal.
